# Politique de Confidentialité

**Dernière mise à jour : 12 septembre 2026**

Cette Politique de Confidentialité explique quelles informations peuvent être traitées lors de l'utilisation de ce bot Discord (ci-après « le Bot »), pourquoi elles sont utilisées et comment elles sont conservées.

## 1. Données pouvant être collectées

Pour assurer son fonctionnement, le Bot peut enregistrer certaines informations fournies par Discord ou générées lors de son utilisation.

Cela peut notamment comprendre :

* l'identifiant Discord de l'utilisateur (User ID) ;
* l'identifiant du serveur Discord (Guild ID) ;
* certaines informations nécessaires concernant le personnage du joueur ;
* la classe choisie ;
* les traits et faiblesses ;
* les statistiques ;
* la progression ;
* l'inventaire ;
* les récompenses ;
* les données générées par les commandes et systèmes du Bot.

Le Bot n'a pas pour objectif de collecter des informations personnelles telles que votre nom réel, votre adresse postale, vos mots de passe ou vos informations bancaires.

## 2. Pourquoi ces données sont utilisées

Les données enregistrées sont utilisées uniquement lorsque cela est nécessaire au fonctionnement du Bot.

Elles peuvent notamment servir à :

* identifier le profil ou personnage associé à un utilisateur Discord ;
* sauvegarder la progression ;
* gérer les statistiques ;
* gérer les classes, traits et faiblesses ;
* gérer les inventaires et récompenses ;
* assurer le fonctionnement des commandes ;
* prévenir certains abus ;
* corriger des bugs ;
* améliorer le fonctionnement du Bot.

## 3. Stockage des données

Certaines données peuvent être conservées dans une base de données afin de permettre au Bot de sauvegarder la progression entre plusieurs utilisations.

Nous prenons des mesures raisonnables afin de protéger ces informations contre les accès non autorisés.

Cependant, aucun système informatique ne peut garantir une sécurité absolue.

## 4. Partage des données

Les données enregistrées par le Bot ne sont pas vendues.

Elles ne sont pas utilisées à des fins publicitaires.

Elles peuvent être accessibles aux personnes chargées du développement, de l'administration ou de la maintenance du Bot lorsque cela est nécessaire à son fonctionnement.

Certaines informations peuvent également être traitées par Discord dans le cadre normal de l'utilisation de sa plateforme.

## 5. Conservation

Les données sont conservées aussi longtemps qu'elles sont nécessaires au fonctionnement du Bot.

Certaines données peuvent être supprimées lorsqu'un utilisateur cesse d'utiliser le service, lorsqu'elles ne sont plus nécessaires ou lorsqu'une suppression est demandée, sous réserve des éventuelles obligations applicables.

## 6. Suppression des données

Un utilisateur peut demander la suppression des données associées à son compte Discord.

Pour permettre l'identification des données concernées, il pourra être demandé de fournir son identifiant Discord (User ID).

La demande peut être effectuée auprès de l'équipe responsable du Bot via le serveur Discord officiel ou le moyen de contact indiqué par le développeur.

## 7. Données sensibles

Le Bot n'est pas conçu pour demander ou stocker volontairement des données sensibles telles que :

* mots de passe ;
* coordonnées bancaires ;
* documents d'identité ;
* adresses postales privées ;
* données médicales.

Les utilisateurs ne doivent pas transmettre ce type d'information au Bot.

## 8. Services tiers

Le Bot fonctionne notamment grâce aux services fournis par Discord.

L'utilisation de Discord reste soumise aux propres conditions et politiques de Discord.

## 9. Modification de cette politique

Cette Politique de Confidentialité peut être mise à jour afin de tenir compte de nouvelles fonctionnalités, de changements techniques ou de nouvelles obligations.

La date de dernière mise à jour est indiquée en haut de cette page.

## 10. Contact

Pour toute question concernant cette Politique de Confidentialité ou pour demander la suppression de données associées à votre compte, veuillez contacter l'équipe responsable du Bot via le serveur Discord officiel ou le moyen de contact indiqué par le développeur.
