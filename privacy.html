Politique de Confidentialité

Dernière mise à jour : 12 septembre 2026

Cette politique explique quelles données peuvent être utilisées par le Bot One Piece et pourquoi elles sont nécessaires à son fonctionnement.

1. Données pouvant être collectées

Pour assurer son fonctionnement, le Bot peut enregistrer certaines informations fournies par Discord ou générées lors de son utilisation.

Cela peut notamment comprendre :

  • l'identifiant Discord de l'utilisateur (User ID) ;
  • l'identifiant du serveur Discord (Guild ID) ;
  • les informations relatives aux personnages ;
  • les classes choisies ;
  • les traits et faiblesses ;
  • les statistiques ;
  • la progression ;
  • les inventaires et objets ;
  • les récompenses ;
  • les données nécessaires au fonctionnement des commandes du Bot.

2. Utilisation des données

Ces données peuvent être utilisées afin de :

  • identifier le profil associé à un utilisateur Discord ;
  • sauvegarder les personnages et leur progression ;
  • gérer les statistiques ;
  • gérer les classes, traits et faiblesses ;
  • gérer les inventaires, objets et récompenses ;
  • assurer le fonctionnement des commandes ;
  • prévenir certains abus ;
  • corriger des bugs et améliorer le Bot.

3. Données personnelles sensibles

Le Bot n'est pas conçu pour demander ou stocker volontairement des informations telles que :

  • les mots de passe ;
  • les coordonnées bancaires ;
  • les documents d'identité ;
  • les adresses postales privées ;
  • les données médicales.

Les utilisateurs ne doivent pas transmettre ce type d'information au Bot.

4. Stockage

Les données nécessaires au fonctionnement du Bot peuvent être enregistrées dans une base de données afin de permettre notamment la sauvegarde de la progression entre plusieurs utilisations.

Des mesures raisonnables sont mises en œuvre afin de limiter les accès non autorisés à ces informations.

5. Partage et vente des données

Les données enregistrées par le Bot ne sont pas vendues et ne sont pas utilisées à des fins publicitaires.

Elles peuvent être accessibles aux personnes chargées du développement, de l'administration ou de la maintenance du Bot lorsque cela est nécessaire à son fonctionnement.

6. Conservation

Les données sont conservées aussi longtemps qu'elles sont nécessaires au fonctionnement du Bot ou à la conservation de la progression du joueur.

7. Suppression des données

Un utilisateur peut demander la suppression des données associées à son compte Discord.

Afin d'identifier les données concernées, son identifiant Discord (User ID) pourra lui être demandé.

La demande doit être adressée à l'équipe responsable du Bot via le serveur Discord officiel ou le moyen de contact communiqué par le développeur.

8. Discord

Le Bot fonctionne grâce aux services proposés par Discord. Certaines données peuvent donc également être traitées directement par Discord conformément aux propres politiques de la plateforme.

9. Modification de cette politique

Cette Politique de Confidentialité peut être mise à jour lorsque les fonctionnalités du Bot ou son fonctionnement évoluent.

10. Contact

Pour toute question relative à cette Politique de Confidentialité ou pour demander la suppression de données associées à votre compte, veuillez contacter l'équipe responsable du Bot.
